## 🤟 LSE Real-Time Translator

**Spanish Sign Language → Spoken Language**

My Bachelor's Thesis: a real-time Spanish Sign Language recognition and translation system developed over **two years**.

The system combines computer vision, machine learning and temporal modelling to recognise **104 static and dynamic signs** and translate them into spoken language in real time.

### Results

|              |                        |
| ------------ | ---------------------- |
| **97.55%**   | Standard accuracy      |
| **83.50%**   | Cross-session accuracy |
| **17.5 FPS** | Real-time inference    |
| **104**      | Recognised signs       |
| **9.6 MB**   | Model size             |
| **CPU-only** | No dedicated GPU       |

**The interesting constraint:** making real-time inference work on ordinary consumer hardware.

# 🚀 Building

## Citalia

**A multi-tenant SaaS platform for clinics and littel business.**

Citalia is a personal software project focused on automating patient communication, lead management and appointment workflows.

The platform brings together:

```text
                    CITALIA
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   Communication     AI Layer      Scheduling
        │              │              │
   WhatsApp         Lead AI       Calendars
   Instagram        Replies       Availability
   Web Forms        Qualification Appointments
        │              │              │
        └──────────────┼──────────────┘
                       │
                 Multi-Tenant
                       │
                PostgreSQL + RLS
```

### Engineering focus

`Next.js` · `TypeScript` · `Supabase` · `PostgreSQL` · `RLS` · `RBAC` · `AI` · `Vercel`

The project is being designed with **tenant isolation, database-level security, authorization boundaries, automated testing, observability and production-oriented architecture** as first-class concerns.

> A large part of the challenge isn't making the application work.
> **It's making sure it keeps working when real users, real data and real failures arrive.**
